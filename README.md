# 👥 Team Task Management System

A full-stack web application designed to help teams organize projects, manage tasks, assign responsibilities, and track work efficiently.

## 🚀 Features

* 👤 User registration and login
* 🔐 Secure authentication
* 📋 Create and manage tasks
* 👥 Assign tasks to team members
* 📊 Track task progress and status
* 🗂️ Organize tasks by projects
* 🎯 Task priority management
* 📱 Responsive user interface
* 🔄 Frontend and backend integration

## 🛠️ Tech Stack

### Frontend

* React.js
* JavaScript
* HTML5
* CSS3

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Siddhikumari16/team-task-management.git
```

### 2. Open the project

```bash
cd team-task-management
```

### 3. Install frontend dependencies

```bash
cd Frontend
npm install
```

### 4. Start the frontend

```bash
npm start
```

### 5. Install backend dependencies

Open another terminal:

```bash
cd backedn
npm install
```

### 6. Start the backend

```bash
npm start
```

> Make sure your backend environment variables and MongoDB connection are configured before starting the server.
